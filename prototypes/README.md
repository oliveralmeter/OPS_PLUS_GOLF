# Earlier prototypes

Before the tkinter desktop version in the repo root, OPS+ Golf was prototyped as a
Streamlit web app.

- `app_streamlit.py` - the Streamlit build of the game (206 lines). Same OPS+ matching
  idea, rendered in the browser instead of a desktop window.
- `hello_streamlit.py` - the throwaway "does Streamlit work" check.
- `app_streamlit.spec` - the PyInstaller spec that went with it.

Kept for history. These are not maintained; `app.py` in the repo root is the real game.
